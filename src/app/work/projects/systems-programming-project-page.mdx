## Overview

These systems programming projects explore compilation, Unix process management, memory allocation, control flow, and signal handling using C, C++, Flex/Bison (Lex/Yacc), x86-64 Assembly, and Linux.

## SimpleC Compiler

Implemented a **single-pass SimpleC-to-x86-64 compiler** with Lex/Yacc, generating code for expressions, arrays, functions, and control flow.

## Unix Shell

Built a **Unix shell** with Flex/Bison parsing and support for:

- Pipelines and I/O redirection.
- Background processes, built-ins, and subshells.
- Expansions, signal handling, and command history.

## Assembly and Debugging Utilities

- Implemented **x86-64 heap sort** with recursive heapify.
- Built **frame-pointer stack unwinding** with signal handlers.
- Implemented hexadecimal memory and file dump utilities.

## Technologies Used

C, C++, Flex/Bison (Lex/Yacc), x86-64 Assembly, and Linux.
